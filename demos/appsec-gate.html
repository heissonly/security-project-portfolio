Risk-based build gate

Real Semgrep, pip-audit and Trivy scans against this repository found 18 blocking issues. Every one got fixed. This page shows that real result, then lets you replay the same rule the Python gate and its tests enforce.

The first scan found 6 dependency CVEs (starlette, via pip-audit) and 12 base-image CVEs (perl-base, libsqlite3, gzip, libpcre2, via Trivy). Fixes: bumped fastapi/starlette/uvicorn, added apt-get upgrade to the Dockerfile, and added namespace + runAsUser/runAsGroup to the Kubernetes manifests. The 44 remaining high-severity findings have no vendor-published fix yet — the gate tracks them instead of blocking a pipeline the team can't act on.
