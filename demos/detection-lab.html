03 / INCIDENT STORY

One chain, four decision points

The project keeps ATT&CK as a coverage taxonomy and uses each signal to answer a concrete analyst question.

  1. 01
    D1 · INITIAL ACCESS SIGNAL

    Password spray threshold crossed

    Six failures across three test users from one reserved IP. Analyst validates the test window, target spread and source context.

    TRIAGE
  2. 02
    D2 · PRIVILEGE CHANGE

    Cloud role membership added

    Audit evidence preserves actor, target, role and correlation identifiers before containment is considered.

    HIGH
  3. 03
    D3 · ENDPOINT CORRELATION

    Encoded PowerShell marker observed

    Event 4104 links controlled endpoint execution to the identity timeline while the paired administrative command stays below the boundary.

    CORRELATE
  4. 04
    D4 · PERSISTENCE SIGNAL

    Application credential modified

    The analyst validates ownership and change approval, then follows the credential revocation and recovery runbook.

INFRASTRUCTURE

Reproducible by design

Terraform provisions Log Analytics, Sentinel onboarding, optional Entra diagnostics, private Windows telemetry, AMA/DCR and scheduled rules.

  • AzureRM 4.81 validated
  • System-assigned VM identity
  • No public IP or inbound NSG rule
AUTOMATION

Analyst support, with limits

A failure-tolerant Python CLI classifies IP, domain and hash indicators and can query VirusTotal and AbuseIPDB through environment-only API keys.

  • JSON and Markdown output
  • Provider errors remain visible
  • No automatic blocking action
RESPONSE

Evidence before containment

Two synthetic investigations connect signal, decision and recovery requirements. Three runbooks retain human approval for disruptive steps.

  • Identity containment
  • Endpoint containment
  • Credential revocation
COST CONTROL

Designed to be destroyed

The deployment script creates a reviewable private plan before apply. Cleanup evidence records Terraform destroy and checks tagged resources.

  • 0.25 GB daily ingestion quota
  • 50/80/100% budget notifications
  • Automatic VM shutdown
